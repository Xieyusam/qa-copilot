# QA Copilot MVP4 - 需求文档

## 1. 项目概述

MVP4 聚焦于 **知识库管理增强** 和 **前端体验优化**，解决 MVP3 遗留的硬编码分类问题，并提升整体界面美观度与交互体验。

### 背景

MVP3 实现了多场景知识库隔离，但存在以下局限：
1. **知识库分类硬编码**：`default/translation/log` 三类固定，无法动态扩展
2. **检索路由不准确**：Agent 无法准确判断应调用哪个知识库工具，导致查询"平台资料"时错误调用翻译/日志知识库
3. **前端界面陈旧**：缺乏统一设计规范，交互反馈不足

### 目标

- 支持用户自定义知识库分类，动态管理
- 优化 Agent 工具选择逻辑，提升检索准确率
- 重构前端 UI，建立统一设计规范，提升用户体验

---

## 2. 核心功能需求

### 2.1 知识库管理增强（管理员专属）

> **权限说明**：知识库管理功能仅对管理员开放，普通用户只能使用对话功能，无法管理文档或分类。

#### 2.1.1 自定义知识库分类

| 功能 | 描述 |
|------|------|
| 创建分类 | 用户可创建新的知识库分类（如 `qa-docs`、`api-reference`） |
| 编辑分类 | 支持修改分类名称和描述 |
| 删除分类 | 删除空分类（无文档的分类），有文档时需先迁移或删除文档 |
| 分类列表 | 显示所有分类及其文档数量 |

#### 2.1.2 文档分类管理（管理员专属）

| 功能 | 描述 |
|------|------|
| 上传时选择分类 | 管理员上传文档时可选择目标分类 |
| 移动文档 | 管理员可将文档从一个分类移动到另一个分类 |
| 删除文档 | 管理员可删除任意文档 |
| 按分类筛选 | 管理员可按分类筛选显示文档列表 |

#### 2.1.3 普通用户权限

| 功能 | 描述 |
|------|------|
| 对话功能 | 普通用户可正常使用 Agent 对话，检索所有知识库 |
| 无管理权限 | 普通用户无法上传、删除、移动文档或管理分类 |

#### 2.1.3 动态工具生成

| 功能 | 描述 |
|------|------|
| 工具动态注册 | 根据数据库中的分类动态生成检索工具（如 `retrieve_qa_docs_kb`） |
| 工具描述优化 | 每个工具包含分类描述，帮助 Agent 正确选择 |

### 2.2 知识库检索优化

#### 2.2.1 系统提示词优化

| 功能 | 描述 |
|------|------|
| 知识库选择规则 | 明确说明各知识库用途和选择优先级 |
| 工具调用策略 | 指导 Agent 如何判断用户意图并选择正确工具 |

#### 2.2.2 工具描述增强

| 功能 | 描述 |
|------|------|
| 用途说明 | 每个工具描述包含该分类存放的内容类型 |
| 使用场景 | 说明什么情况下应该/不应该调用此工具 |

### 2.3 前端界面优化

#### 2.3.1 设计规范统一

| 规范项 | 描述 |
|------|------|
| 颜色体系 | 建立主色、辅色、状态色（成功/警告/错误）体系 |
| 字体规范 | 统一字号层级（标题/正文/辅助文本）、字重 |
| 间距规范 | 统一 padding、margin、gap 值（4px/8px/16px/24px） |
| 圆角规范 | 统一圆角值（小: 4px, 中: 8px, 大: 12px） |

#### 2.3.2 排版优化

| 功能 | 描述 |
|------|------|
| 信息层级 | 优化标题、内容、操作的视觉层级 |
| 卡片设计 | 统一卡片样式，提升内容区分度 |
| 响应式适配 | 优化不同屏幕尺寸下的布局 |

#### 2.3.3 交互体验增强

| 功能 | 描述 |
|------|------|
| 加载状态 | 优化 loading 动画，显示进度提示 |
| 操作反馈 | 点击、上传、删除等操作有明确反馈（Toast/动画） |
| 空状态设计 | 空列表/空对话有引导性提示 |
| 过渡动效 | 页面切换、元素出现/消失有平滑过渡 |

## 3. 非功能性需求

| 类别 | 需求 |
|------|------|
| 性能 | 前端首屏加载 < 2s，文档列表渲染 < 500ms |
| 兼容性 | 支持 Chrome、Edge、Firefox 最新版本 |
| 可维护性 | 设计规范文档化，便于后续扩展 |
| 安全性 | 知识库管理 API 需校验管理员权限，普通用户调用返回 403 Forbidden |

## 4. 验收标准

### 4.1 知识库管理（管理员功能）

- [ ] 管理员可创建、编辑、删除自定义分类
- [ ] 管理员上传文档时可选择目标分类
- [ ] 管理员可将文档从一个分类移动到另一个分类
- [ ] 管理员可按分类筛选显示文档列表
- [ ] 普通用户调用管理 API 返回 403 Forbidden
- [ ] Agent 根据自定义分类动态生成检索工具（对所有用户可用）

### 4.2 检索准确率

- [ ] 查询"平台资料"时，正确调用对应知识库工具
- [ ] 系统提示词包含知识库选择规则

### 4.3 前端体验

- [ ] 建立统一设计规范文档
- [ ] 所有页面符合新设计规范
- [ ] 关键操作有明确交互反馈
- [ ] 空状态有引导性设计

---

## 5. 约束与假设

### 约束

- 不引入新的第三方 UI 库，基于 Tailwind CSS 实现
- 分类数量上限为 20 个（防止工具过多影响 Agent 性能）
- 知识库管理功能仅管理员可用，普通用户无管理权限
- 删除分类前需确保分类下无文档

### 假设

- 用户对知识库分类有基本理解
- Agent 工具数量增加不会显著影响响应速度
